# KeyboardTypist

KeyboardTypist is a Windows typing application designed to help users practise and improve their typing speed.

## How to use

1. Download `KeyboardTypist-Windows.zip` from the Releases section.
2. Extract the ZIP file on your Windows PC.
3. Open the extracted folder and run `KeyboardTypist.exe`.

## Stopping the app

Press **F8** to stop the app.

## Download

Get the Windows version from the [Releases page](https://github.com/Solomon1324/KeyboardTypist/releases).
